# WDD430 Portfolio

**Live Deployment URL:** https://wdd430-portfolio-rosy.vercel.app

## Project Overview
A professional portfolio application built with Next.js, React, TypeScript, and Tailwind CSS for the WDD430 course.

## Getting Started
First, run the development server:

\`\`\`bash
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
